# services-dynamiques-Bri

Le projet est une introduction aux services dynamiques, inspirée de la plateforme OSGi. Il vise à créer un espace d'échange entre :
Programmeurs Java professionnels qui développent divers services comme :
- Service de mail,
- Analyse syntaxique XML,
- Journalisation d'activités, etc.

Non-programmeurs amateurs, qui utilisent ces services sans expertise technique.

Objectif principal :
Familiariser les participants avec les bases de plateformes complexes comme OSGi en mettant l'accent sur l'interaction entre créateurs de services et utilisateurs.

Détails importants :
- Non-programmeurs (amateurs) : Ils représentent les utilisateurs finaux des services, sans compétences techniques avancées.
- Professionnels : Ils sont les développeurs des services dynamiques en Java.
- Aspects facultatifs (entre parenthèses dans le texte) : Pour ceux qui souhaitent approfondir avec des fonctionnalités plus complexes.

Le projet n’a pas pour but de maîtriser entièrement OSGi, mais de comprendre ses concepts fondamentaux et de les appliquer de manière simplifiée.
